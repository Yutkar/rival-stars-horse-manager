# Rival Stars Horse Manager

Русскоязычный адаптивный сайт для управления конюшней в Rival Stars Horse Racing.

## Запуск на Windows

1. Установите Node.js (версия 20.19+ или 22+).
2. Распакуйте ZIP и откройте папку проекта в VS Code.
3. В терминале выполните:

```powershell
npm install
npm run dev
```

4. Откройте адрес, показанный Vite (обычно http://localhost:5173).

## Телефон

Подключите телефон и ноутбук к одной сети Wi-Fi. При запущенном `npm run dev` откройте на телефоне сетевой адрес, который Vite покажет в строке `Network` (например, `http://192.168.1.10:5173`). Если соединение блокируется, проверьте брандмауэр Windows. На телефоне будет **своя отдельная база** — браузерное хранилище автоматически между устройствами не синхронизируется. Переносите данные через «Экспорт» и «Импорт».

## Возможности

- Создание, редактирование, удаление и дублирование карточек.
- 5 характеристик × 3 показателя: 1 уровень, максимальный потенциал, буква.
- Рейтинги, фильтр по звёздам, сортировка по каждой характеристике.
- Настраиваемые веса и отдельные режимы «Скачки» и «Кросс».
- Попарное сравнение.
- Автосохранение в localStorage и резервные копии JSON.
- Загрузка скриншота и **экспериментальное OCR** с Tesseract.js; распознавание может быть неполным, обязательна ручная проверка.

## Важно

Рейтинг — пользовательская эвристика, а не официальная формула Rival Stars. По умолчанию смешиваются 30% значения первого уровня, 50% максимальные и 20% буквенные оценки; для сравнения разных звёздных классов рекомендуется фильтр по звёздам. При очистке данных браузера localStorage может исчезнуть: периодически экспортируйте JSON.

Скриншоты и данные хранятся локально; **сами изображения не сохраняются**. При первом использовании OCR может потребоваться интернет для загрузки языковой модели.

## Публикация на GitHub Pages

1. Создайте **публичный** репозиторий с именем `rival-stars-horse-manager`.
2. Загрузите **содержимое** папки проекта в корень репозитория, включая скрытую папку `.github` и файл `.gitignore`.
3. Убедитесь, что ветка называется `main`.
4. В репозитории откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**.
5. Перейдите в **Actions** и дождитесь успешного выполнения `Deploy to GitHub Pages`. Если workflow не стартовал, запустите его вручную через **Run workflow**.
6. Сайт будет доступен по адресу `https://<username>.github.io/rival-stars-horse-manager/`.

При каждом push в `main` сайт пересобирается и публикуется автоматически. Для локальной разработки используется `/`, для GitHub Pages — `/rival-stars-horse-manager/` (переменная `GITHUB_PAGES=true` в workflow).

**Важно:** если имя репозитория будет другим, измените путь `base` в `vite.config.ts`. Данные хранятся в `localStorage` каждого браузера; GitHub Pages не синхронизирует базу между устройствами. Пользуйтесь экспортом/импортом JSON для резервных копий.

**Проверка:** в среде подготовки архива установка npm-зависимостей завершилась по тайм-ауту, поэтому успешная сборка не подтверждена. После загрузки проверьте статус GitHub Actions.
